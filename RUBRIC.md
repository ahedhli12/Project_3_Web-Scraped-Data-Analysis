# CMP 262 — Project 3 Rubric
**Total: 100 points.** Categories, weights, and performance bands follow the instructor-supplied **Project Rubric CMP 262.pdf**. The checks below explain how those categories apply to this project.

| Criterion | Points | What the instructor will review |
|---|---:|---|
| Project repository located on GitHub | 10 | Accessible student repository and correct repository link submitted in Blackboard Ultra |
| Repository contains required files | 10 | Notebook with outputs, completed README summary and AI-use report, raw CSV, page log, cleaned CSV, and at least two chart PNGs |
| Analysis demonstrates acquired skills | 40 | Working requests/Beautiful Soup pipeline collecting records from at least five distinct pages; pandas DataFrame; appropriate cleaning checks and decisions; four questions answered by code output |
| Study conclusions | 10 | Four written answers supported by computed results, overall findings, and limitations |
| Plot design strategies | 10 | Seaborn plots answer at least two questions; conclusion-based titles, axis labels/units, data labels or numeric annotations, and readable styling |
| Analysis is organized | 10 | Logical notebook sections and a clear flow from source plan to collection, cleaning, analysis, and conclusions |
| Analysis is documented | 10 | Useful Python comments, Markdown explanations, source and selector details, dated robots.txt/policy review, and explanation of cleaning choices |
| **Total** | **100** | |

For each 10-point category: **7–10 = Successful; 0–6 = Needs Improvement**.
For the 40-point analysis category: **28–40 = Successful; 0–27 = Needs Improvement**.

Partial credit depends on the completeness and correctness of the submitted work. A pipeline that silently collects fewer than five pages is incomplete, even if its plots run.
